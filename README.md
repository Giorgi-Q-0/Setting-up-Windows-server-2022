# Setting-up-Windows-server-2022
I worked with server for the first time.
Everything went pretty smoothly,With no errors and confusion.

1. First i downloaded Windows Server 2022 ISO from official website (English version)

2. I attached downloaded ISO to Virtualbox, i changed "Graphics Controller" from <b>"VBoxVGA" to "VMSVGA"</b>, because VBoxVGA just gives you Blank screen.

3. Once everything was set, i launched server with <b>"Start with GUI"</b> <br>
4. After it started i picked <br>'Windows Server 2022 Standard Evaluation (Desktop Experience)'</br> because it gives you the best experience.<br>
5. When everything was configured it worked perfectly fine.
